GWRC

Greater Wellington Regional Council ~26,569 records MapServer Integrated ✓
Endpoint: mapping.gw.govt.nz — Resource_Consents_P/MapServer/0
File: All_Consents_GWRC.geojson
Server type: MapServer (not FeatureServer)
Documents: concessions.gw.govt.nz/documents/archive
Uses MapServer endpoint — pagination flag exceededTransferLimit is at the JSON root, not inside properties like FeatureServer. Date fields (commencement_date, ExpiredDate, ElapsedDate) are stored as DD/MM/YYYY strings — parsed by a dedicated ddmmyyyyToIso() converter, not the standard timestamp converter. No holder name or site address fields are published. Document links are constructed from RC_CON_FILENO as a search URL against the GWRC document archive.

GDC

Gisborne District Council (Tairāwhiti) ~22,882 records MapServer Integrated ✓
Endpoint: maps.gdc.govt.nz/hosting/rest/services/Property/resource_consents_ext/MapServer/0
File: All_Consents_GDC.geojson
Server type: MapServer
Coordinate system: NZTM2000 (EPSG:2193) — fetched with outSR=4326
Uses MapServer (like GWRC) — exceededTransferLimit flag is at the JSON root. Dates are stored as Unix millisecond timestamps and converted by arcgisTimestampToIso(). Publishes all consent statuses (Active, Expired, Granted, Cancelled, Closed, Deferred, Lapsed, Refused, Surrendered, Varied, Withdrawn). No applicant name is available — the source only provides FirstApplicantId (an internal numeric ID, not a name). Some records have no valid geometry (ungeocoded sites) and are silently dropped by the coordinate validation filter.

AC

Auckland Council ~unknown records ✗ Not Publicly Accessible
Public portal: data-aucklandcouncil.opendata.arcgis.com
ArcGIS Server: mapspublic.aucklandcouncil.govt.nz/arcgis3
⛔ Auckland Council does not provide a publicly accessible ArcGIS endpoint for resource consent data.

All requests to their ArcGIS REST services return: {"error":{"code":499,"message":"Token Required"}}

Their open data portal (data-aucklandcouncil.opendata.arcgis.com) lists 200+ datasets but no resource consent database is published publicly. Resource consent data for Auckland is only available through their internal consent portal or by request.

Alternatives to explore: LAWA (Land Air Water Aotearoa), data.govt.nz dataset request, or direct contact with Auckland Council GIS team under an Official Information Act request.
No public field schema available — endpoint requires authentication token
